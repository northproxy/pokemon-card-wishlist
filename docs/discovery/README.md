# Data Discovery

This directory contains the documented results of source-data investigation for `M0 — Discovery`.

The discovery process covers:

- source-file inventory;
- source-field analysis;
- catalogue-record identity;
- stable identifier candidates;
- expansion mapping;
- language and variant representation;
- image mapping;
- data-quality findings;
- selection of the first expansion for the vertical slice.

Documents in this directory describe validated observations, unresolved questions, and evidence-based recommendations. They must not present preliminary assumptions as final database decisions.
